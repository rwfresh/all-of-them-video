A 44-second 1998 TV infomercial taped on VHS, every frame drawn in code. It opens in black and white on a desktop drowning in multiplying error boxes: 'STILL WRITING CODE BY HAND?', with the Dial-A-Dev 98 name and 1-800 number in a lower third from the first frame. The chrome Dial-A-Dev 98 logo slams in: 'The A.I. Coding Agent'. The retail box lands and 14 CD-ROMs fly out into a rainbow arch. In the desktop app the user types 'make me a web site for my band with flames. no bugs please' in plain English and presses Dial; a modem handshake ends in 'CONNECTED at 56,000 bps'. Code streams while the band's home page builds overnight and the clock runs to 7:00 AM: 'SHIPS BY MORNING!'. Phone-Line Guard padlocks the phone and blocks Mom, the sister and the fax machine. 'BUT WAIT! THERE'S MORE!': 500 free hours of context, 3 easy payments of $19.95, call 1-800-555-0198. Then Mom picks up the phone: NO CARRIER, stamped 'DO NOT PICK UP THE PHONE'.
