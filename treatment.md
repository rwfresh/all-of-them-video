# All of Them: treatment

**One idea, one line:** one Claude Code session makes a film, and every step of the making is drawn in a different
motion-design style, so the terminal you start in is the only thing that never changes.

- A person types `make me a video.` Claude asks `In what style?` The answer is `all of them.`
- From there each prompt is a real step of making a film in code (the idea, stills first, the cue sheet, the shots,
  motion, transitions, sound, how it works, the render, playback, the jury, the fixes, the polish, the final cut,
  posting), and each step arrives in the style that suits it: fifteen styles, after the set at
  github.com/Vincentwei1021/mg-styles-15.
- The terminal's two rows and the cursor survive every change. Styles never cut: each one does what it does to the
  picture before it.
- The hero is the tenth style: `play it.` starts a tape, and the film's own title lands in chrome on the music's drop.
- The film ends where it began, in the plain terminal: `Your turn.`

38 bars at 124 BPM, 73.55 s, 1920x1080 at 60 frames a second, music and sound effects only. Every frame is drawn by
code in a web page; the sound is generated (ElevenLabs), so the film claims the picture only. Shot by shot: `BRIEFS.md`.
